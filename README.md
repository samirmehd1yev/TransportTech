# TransportTech

[Ayna_IsmatSamadov.ipynb](notebooks/Ayna_IsmatSamadov.ipynb) contains the AYNA hackathon calculations and a short recommendation in Azerbaijani.

- [data/](data/) — original KMZ datasets.
- [docs/](docs/) — [task brief](docs/hackathon-task.docx) and [environment setup](docs/setup.md).
- [notebooks/](notebooks/) — submission notebook.

## Run the notebook

From this project directory:

```sh
source .venv/bin/activate
python -m jupyterlab notebooks/Ayna_IsmatSamadov.ipynb
```

Select the project's `.venv` kernel and run all cells. The notebook reads from `data/` and works from the project root or `notebooks/`.

For submission, send only `notebooks/Ayna_IsmatSamadov.ipynb`.
